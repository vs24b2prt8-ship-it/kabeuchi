# 壁打ちトーク（Web版）

ゲームや手作業をしながら考え事を声に出し、AIと壁打ちして思考を進めるツール。
自宅PCのサーバーに依存しない静的PWA版。

- 音声 → Groq Whisper で文字起こし → Groq LLM が短く返答 → ブラウザTTSで読み上げ
- 深掘りモード: ①話す（声）→ ②整理する → ③決める → ④試す（見ずに再現して採点）
- 会話ログ・テーマ・確定ストックは **端末の localStorage のみ** に保存

## 使い方

1. ページを開く
2. 右上「設定」に自分の Groq APIキー（`gsk_...`）を入れて保存
3. マイクボタンで開始。しゃべって黙ると自動送信

キーもログも端末から出ません（Groq APIへの送信を除く）。

## データの持ち運び

設定 → エクスポート / インポート で端末間を移せます。
PC版から移す場合は PC 側で `python export_for_web.py` を実行し、
出力された JSON をインポートしてください。
